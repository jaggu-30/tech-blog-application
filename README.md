# Inkly — Responsive Blog Application

A front-end blog application built with HTML, CSS, and vanilla JavaScript.

## Included pages

- Home page with featured stories
- Login and registration pages with form validation
- Dashboard with article statistics and published stories
- Create Blog page with a publish flow

## Run locally

Open `index.html` in any modern web browser. No installation is required.

## Interaction notes

Account name and published posts are stored locally in the browser, so they remain available after a refresh on the same device.
